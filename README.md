# school-off — школьный помощник для родителя

Учёт для родителя: что задано, сделано ли, какие оценки, что сказали учителя — и на что обратить внимание прямо сейчас.

Статический сайт без сервера и сборки. Все данные хранятся **только в браузере** устройства (localStorage + IndexedDB для фото), в репозиторий и в сеть ничего не уходит.

## Что умеет (v0.1)

- Несколько детей, у каждого свой класс и значок.
- **Расписание на неделю:** уроки по дням, номера, время, кабинет. Срок нового задания подставляется по ближайшему уроку предмета; в обзоре виден завтрашний день.
- Имя и класс ребёнка можно изменить (✏️ в шапке профиля).
- **Задания:** предмет, текст, срок, фото; статусы «в работе → сделано → проверено»; просрочка подсвечивается.
- **Оценки:** предмет, вид работы, дата, комментарий, фото; средний балл и тренд по предметам.
- **Замечания и похвалы** учителей с датой, предметом и фото.
- **«На что обратить внимание»:** просрочка, ждёт проверки, низкие оценки за 2 недели, предметы со средним ниже 3,5 или с падающими оценками, повторяющиеся замечания.
- **Еженедельная сводка** (вкладка «Неделя»): сделано заданий, средний балл в сравнении с прошлой неделей, замечания и похвалы, что тревожит и что делать дальше; переключение по неделям; кнопка «Скопировать текст» для отправки в мессенджер.
- **Подтянуть** (вкладка): предметы, где просадка за 2 недели, с причинами и планом занятий; по кнопке ИИ подбирает тренировочные задания на тему (с ответами и подсказками для родителя), которые можно сохранить, распечатать или добавить в «Задания».
- **Из дневника по фото:** ИИ читает страницу дневника и предлагает задания, оценки и замечания — вы проверяете и подтверждаете, прежде чем что-то сохранится.
- **Напоминания:** баннер на главной (просрочено, на сегодня, на завтра, ждёт проверки) и файл календаря `.ics` — телефон сам напомнит о каждом задании накануне вечером и о ежедневной проверке уроков.
- Резервная копия: скачать/загрузить файл (переносит данные между устройствами).
- Работает как приложение на телефоне (PWA: «Добавить на главный экран»), фото можно снимать прямо с камеры.

## ИИ-функции: что нужно знать

Работают через **ваш собственный ключ Claude API** (console.anthropic.com → API keys). Без ключа остальное приложение работает как раньше.

- Ключ вводится в ⚙️ → «ИИ-помощник» и хранится **только в этом браузере** (localStorage). В репозиторий и в резервную копию он не попадает, а запросы идут напрямую на `api.anthropic.com` — без посредников и без сторонних библиотек.
- Любой, кто пользуется этим браузером, может увидеть ключ. Не вводите его на чужих устройствах и задайте в консоли Anthropic лимит расходов для ключа.
- Оплата идёт по факту использования. Модель выбирается в настройках (по умолчанию Claude Opus 5.5 — самая точная; Sonnet 5.5 и Haiku 4.5 дешевле, но хуже читают почерк).
- Фото и тексты заданий отправляются в Anthropic. Имя ребёнка программа не отправляет, но на фото дневника оно может быть видно — снимайте так, чтобы оно не попало в кадр.
- ИИ может ошибаться: распознанное вы подтверждаете вручную, а ответы к заданиям стоит быстро просмотреть.

## Запуск локально

```bash
npm start        # http://localhost:8080
npm test         # тесты логики
```

## Публикация на GitHub Pages

Settings → Pages → Source: **Deploy from a branch** → `main` / `/ (root)`. Сайт появится по адресу
`https://<пользователь>.github.io/school-off/`.

> Бесплатные GitHub Pages работают для публичных репозиториев. Это безопасно: код открыт, а данные детей остаются в браузере и в репозиторий не попадают. Файлы резервных копий (`school-off-*.json`) добавлены в `.gitignore`.

## Ограничения

- Данные живут в конкретном браузере на конкретном устройстве. Телефон и ПК не синхронизируются сами — переносите через резервную копию. Автосинхронизация — возможный следующий шаг.
- Очистка данных сайта в браузере удалит записи. Делайте копию время от времени.

## Структура

- `js/logic.js` — даты, статусы, статистика, правила «внимания» (покрыто тестами в `tests/`)
- `js/week.js` — еженедельная сводка и её текст (тесты в `tests/week.test.js`)
- `js/aimap.js` — промпты, схемы и проверка ответов ИИ; `js/ai.js` — вызов Claude API; `js/remind.js` — напоминания и `.ics`
- `js/store.js` — хранилище, фото, экспорт/импорт
- `js/app.js` — интерфейс
